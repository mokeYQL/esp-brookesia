### 核心概念

#### 1. Context（系统上下文）
**作用**：整个框架的核心，管理所有资源
**主要功能**：
- 管理显示设备
- 管理输入设备
- 协调 Manager
- 提供事件注册机制
- 提供 LVGL 锁机制

**关键方法**：
```cpp
Context core;
core.begin(config);              // 初始化
core.getManager();              // 获取 Manager
core.getDisplay();              // 获取 Display
core.lockLVGL();               // 加锁
core.unlockLVGL();             // 解锁
```

#### 2. Manager（应用管理器）
**作用**：管理应用的生命周期
**主要功能**：
- 安装/卸载应用
- 启动/停止应用
- 暂停/恢复应用
- 应用切换

**关键方法**：
```cpp
Manager &manager = core.getManager();
manager.begin();                    // 初始化
manager.installApp(app);            // 安装
manager.startApp(id);               // 启动
manager.stopApp(id);                // 停止
manager.uninstallApp(app);          // 卸载
```

#### 3. App（应用基类）
**作用**：所有用户应用的基类
**生命周期**：
```
init() → run() → pause() → resume() → close() → deinit()
  ↑                                            ↓
  └──────────────────────────────────────────────┘
```

**关键方法**：
```cpp
class MyApp : public App {
    bool init() override;      // 安装时（一次）
    bool run() override = 0;  // 运行时（必须）
    bool back() override;      // 返回键
    bool pause() override;     // 暂停
    bool resume() override;    // 恢复
    bool close() override;     // 关闭
    bool deinit() override;   // 卸载时（一次）
};
```

### 代码实现

#### 应用类定义
```cpp
class HelloWorldApp : public App {
public:
    const char *getName() const override {
        return "Hello World";
    }

    bool init() override {
        printf("[HelloWorld] init() called\n");
        return true;
    }

    bool run() override {
        lv_obj_t *screen = getActiveScreen();
        lv_obj_t *label = lv_label_create(screen);
        lv_label_set_text(label, "Hello, ESP-Brookesia!");
        lv_obj_center(label);
        return true;
    }

    // ... 其他生命周期方法
};
```

#### 主函数流程
```cpp
void app_main(void) {
    // 1. 创建并初始化 Context
    Context core;
    core.begin(config);

    // 2. 获取并初始化 Manager
    Manager &manager = core.getManager();
    manager.begin();

    // 3. 创建应用
    auto app = std::make_shared<HelloWorldApp>();

    // 4. 安装应用
    int app_id = manager.installApp(app.get());

    // 5. 启动应用
    manager.startApp(app_id);

    // 6. 主循环
    while (true) {
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```
