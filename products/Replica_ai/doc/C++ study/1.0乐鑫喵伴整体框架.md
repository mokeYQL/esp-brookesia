## 1. 项目架构深度解析

### 1.1 三层架构设计

ESP-Brookesia 采用经典的三层架构设计，实现了硬件与应用的有效隔离：

```
┌─────────────────────────────────────────────────────────┐
│                     Application Layer                   │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────────────┐ │
│  │   Apps  │ │  AI     │ │  Agent  │ │  Protocol       │ │
│  └─────────┘ └─────────┘ └─────────┘ └─────────────────┘ │
├─────────────────────────────────────────────────────────┤
│                     Middle Layer                        │
│  ┌─────────────┐ ┌───────────────────────────────────┐ │
│  │ Function    │ │ System Services                   │ │
│  │ Components  │ │ - Storage Services                │ │
│  │ - Audio     │ │ - Network Services                │ │
│  │ - Display   │ │ - Power Management                │ │
│  │ - Sensor    │ │ - System Management               │ │
│  └─────────────┘ └───────────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│                     HAL Layer                           │
│  ┌───────────────────────────────────────────────────┐ │
│  │ ESP-IDF Hardware Abstraction Layer                │ │
│  └───────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

## 2. 核心组件深入学习

### 2.1 存储服务 (StorageNVS)

**功能**：基于 ESP-IDF NVS 实现的键值对存储服务

**核心实现**：

```cpp
// 服务初始化
auto &storage_service = StorageNVS::requestInstance();
storage_service.begin();

// 数据读写
StorageNVS::Value value;
storage_service.getLocalParam(Manager::SETTINGS_VOLUME, value);
storage_service.setLocalParam(Manager::SETTINGS_VOLUME, value);

// 事件监听
storage_service.connectEventSignal([&](const StorageNVS::Event &event) {
    // 处理事件
});
```

### 2.2 GUI 框架

**功能**：基于 LVGL 的图形界面框架，支持样式表管理

**核心组件**：

- **Style 系统**：支持主题和样式表管理
- **Widget 系统**：预定义的 UI 组件
- **样式表校准**：根据屏幕尺寸自动适配

**样式表管理**：

```cpp
struct Stylesheet {
    base::Context::Data core;
    Display::Data display;
    Manager::Data manager;
    AI_Buddy::Data ai_buddy;
};

using StylesheetManager = gui::StylesheetManager<Stylesheet>;
```

### 2.3 AI 框架

**功能**：支持 AI 交互的框架，兼容主流 LLM 模型

**核心组件**：

- **Agent**：AI 代理管理
- **AI_Buddy**：AI 交互框架
- **Coze 集成**：支持 Coze 平台

**实现示例**：

```cpp
// AI 代理配置
Agent::requestInstance()->configCozeAgentConfig(agent_info, robot_infos);

// 发送事件
agent->sendChatEvent(Agent::ChatEvent::Start, true, 5000);
```

### 2.4 应用管理系统

**功能**：基于 app 的应用管理方式，支持多应用共存

**应用生命周期**：

- `init()`：应用初始化
- `run()`：应用运行
- `back()`：返回上一级
- `close()`：关闭应用
- `deinit()`：应用反初始化

**应用实现示例**：

```cpp
class Settings: public systems::speaker::App, public SettingsStylesheet {
protected:
    bool run() override;
    bool back() override;
    bool close() override;
    bool init() override;
    bool deinit() override;
};
```

## 4. 设计理念与最佳实践

### 4.1 面向对象设计

- 采用 C++ 面向对象设计
- 支持单例模式（`requestInstance()`）
- 支持继承和多态
- 命名空间清晰分离

### 4.2 模块化设计

- 功能模块化，便于维护和扩展
- 模块间低耦合，高内聚
- 统一的初始化和反初始化接口

### 4.3 配置驱动设计

- 支持配置文件管理
- 支持样式表动态切换
- 支持多屏幕尺寸适配

### 4.4 事件驱动架构

- 支持事件信号机制
- 异步事件处理
- 低功耗设计
