## 1. 组件架构总览

### 1.1 组件分层

```
┌─────────────────────────────────────────────┐
│        Application Layer (应用层)          │
│    用户继承 App 开发自定义应用            │
└────────────────┬────────────────────────────┘
                 │
    ┌────────────┴────────────┐
    │                         │
┌───▼──────────┐    ┌───────▼────────────┐
│ Speaker 系统   │    │  Phone 系统 (*)    │
│ (音箱专用)     │    │  (手机专用)         │
└───┬──────────┘    └───────┬────────────┘
    │                        │
    └────────┬───────────────┘
             │
       ┌─────▼────────┐
       │  Base 系统   │  ⭐ 核心基础
       └─────┬────────┘
             │
    ┌────────┴────────┐
    │                 │
┌───▼────────┐  ┌───▼─────────┐
│ GUI 系统   │  │ AI 框架    │
│ (图形界面) │  │ (AI 交互)  │
└───┬────────┘  └───┬─────────┘
    │               │
    └───────┬───────┘
            │
      ┌─────▼────────┐
      │  Services    │  ⭐ 服务层
      │  (存储等)    │
      └──────────────┘
```

### 1.2 组件依赖关系

```
App (你的应用)
    ↓ 使用
Context (系统上下文)
    ↓ 包含
├── Manager (应用管理)
├── Display (显示管理)
└── Event (事件系统)
    ↓ 使用
GUI (图形界面)
    ↓ 包含
├── Style System (样式系统)
├── LVGL Wrapper (LVGL 封装)
└── Anim Player (动画播放)
```

### 1.3 组件学习顺序

**推荐顺序**（按依赖关系和复杂度）：

```
第 1 步：systems/base (核心基础)
    ↓
第 2 步：gui (图形界面)
    ↓
第 3 步：services (服务)
    ↓
第 4 步：ai_framework (AI 框架)
    ↓
第 5 步：systems/speaker (音箱系统)
```

### 2.1 Context 类（系统上下文）

**核心作用**：整个框架的"大脑"，管理所有资源

#### 🎯 核心方法速查

| 分类 | 方法名 | 返回值 | 说明 |
|------|--------|--------|------|
| **获取组件** | `getDisplay()` | `Display&` | 获取显示器 |
| | `getManager()` | `Manager&` | 获取应用管理器 |
| | `getEvent()` | `Event&` | 获取事件系统 |
| **事件注册** | `registerDateUpdateEventCallback()` | `bool` | 注册数据更新回调 |
| | `registerNavigateEventCallback()` | `bool` | 注册导航回调 |
| | `registerAppEventCallback()` | `bool` | 注册应用回调 |
| **事件发送** | `sendDataUpdateEvent()` | `bool` | 发送数据更新事件 |
| | `sendNavigateEvent()` | `bool` | 发送导航事件 |
| | `sendAppEvent()` | `bool` | 发送应用事件 |
| **线程安全** | `lockLv()` | `bool` | 锁定 LVGL |
| | `unlockLv()` | `bool` | 解锁 LVGL |
| **应用管理** | `initAppFromRegistry()` | `bool` | 从注册表初始化应用 |
| | `installAppFromRegistry()` | `bool` | 批量安装应用 |

#### 💡 使用场景

```cpp
// 场景 1: 创建系统上下文
Context core;
Context::Config config = {
    .core_data = {
        .screen_size = {360, 360},

// 场景 2: 获取各个组件
Manager &manager = core.getManager();
Display &display = core.getDisplay();
Event &event = core.getEvent();

// 场景 3: 线程安全操作 LVGL
core.lockLv();
// ... 操作 LVGL 对象
core.unlockLv();

// 场景 4: 发送事件
core.sendDataUpdateEvent();
```

| | `getRunningAppById(int id)` | `App*` | 获取运行中应用 |

```cpp
manager.installAppFromRegistry(app_infos);

// 场景 3: 查询和切换应用
App *current_app = manager.getActiveApp();
App *target_app = manager.getInstalledApp(target_id);
manager.startApp(target_app->getId());
```

### 2.3 App 类（应用基类）

**核心作用**：所有应用的"蓝图"，定义应用生命周期

#### 🎯 必须实现的方法（纯虚函数）

| 方法名 | 返回值 | 说明 |
|--------|--------|------|
| `run()` | `bool` | **应用运行入口**，在这里创建所有 UI |
| `back()` | `bool` | **返回事件处理**，处理用户按返回键 |

#### 🎯 可选重写的方法

| 方法名 | 返回值 | 调用时机 |
|--------|--------|----------|
| `init()` | `bool` | 应用安装时（只调用一次） |
| `deinit()` | `bool` | 应用卸载时（只调用一次） |
| `pause()` | `bool` | 应用暂停时（切换到后台） |
| `resume()` | `bool` | 应用恢复时（切换回前台） |
| `close()` | `bool` | 应用关闭时 |
| `cleanResource()` | `bool` | 清理未自动管理的资源 |

#### 🎯 公共方法

| 方法名 | 返回值 | 说明 |
|--------|--------|------|
| `getId()` | `int` | 获取应用唯一 ID |
| `getName()` | `const char*` | 获取应用名称 |
| `getLauncherIcon()` | `const StyleImage&` | 获取启动器图标 |
| `getVisualArea()` | `const lv_area_t&` | 获取可视区域 |
| `getSystemContext()` | `Context*` | 获取系统上下文 |
| `getActiveScreen()` | `lv_obj_t*` | 获取当前屏幕 |

#### 💡 使用场景

```cpp
class MyApp : public App {
public:
    // 应用配置
    const char *getName() const override {
        return "My First App";
    }

    // 生命周期方法
    bool init() override {
        printf("[App] init() called\n");
        return true;
    }

    bool run() override {
        // 获取屏幕
        lv_obj_t *screen = getActiveScreen();

        // 创建 UI
        lv_obj_t *label = lv_label_create(screen);
        lv_label_set_text(label, "Hello World");
        lv_obj_center(label);

        return true;
    }

    bool back() override {
        printf("[App] back() called\n");
        return false;  // 返回 false 让系统处理
    }

    bool pause() override {
        printf("[App] pause() called\n");
        return true;
    }

    bool resume() override {
        printf("[App] resume() called\n");
        return true;
    }

    bool close() override {
        printf("[App] close() called\n");
        return true;
    }

    bool deinit() override {
        printf("[App] deinit() called\n");
        return true;
    }
};
```

#### 🔄 生命周期调用顺序

```
应用安装
    ↓
init()          ← 只调用一次
    ↓
[等待启动]
    ↓
run()           ← 创建 UI
    ↓
[运行中...]
    ↓
pause()         ← 切换到后台
    ↓
resume()        ← 切换回前台
    ↓
close()         ← 关闭应用
    ↓
deinit()        ← 只调用一次
```

### 2.5 Event 类（事件系统）

**核心作用**：事件的"调度中心"，管理事件处理

#### 🎯 核心方法速查

| 分类 | 方法名 | 返回值 | 说明 |
|------|--------|--------|------|

| | `registerDateUpdateEventCallback()` | `bool` | 注册数据更新回调 |

| | `registerAppEventCallback()` | `bool` | 注册应用回调 |
| **事件发送** | `sendEvent()` | `bool` | 发送事件 |
| | `sendDataUpdateEvent()` | `bool` | 发送数据更新事件 |
| | `sendNavigateEvent()` | `bool` | 发送导航事件 |
| | `sendAppEvent()` | `bool` | 发送应用事件 |
| **事件注销** | `unregisterEvent()` | `void` | 注销事件处理器 |
| | `unregisterDateUpdateEventCallback()` | `bool` | 注销数据更新回调 |
| | `unregisterNavigateEventCallback()` | `bool` | 注销导航回调 |
| | `unregisterAppEventCallback()` | `bool` | 注销应用回调 |

#### 💡 使用场景

```cpp
// 场景 1: 注册应用事件
core.registerAppEventCallback([](lv_event_t *e) {
    Context::AppEventData *data = (Context::AppEventData *)lv_event_get_param(e);
    if (data->type == Context::AppEventType::START) {
        printf("App %d started\n", data->id);
    }
}, nullptr);

// 场景 2: 注册导航事件
core.registerNavigateEventCallback([](lv_event_t *e) {
    void *param = lv_event_get_param(e);
    Manager::NavigateType nav_type;
    memcpy(&nav_type, &param, sizeof(nav_type));
    if (nav_type == Manager::NavigateType::BACK) {
        printf("Back button pressed\n");
    }
}, nullptr);

// 场景 3: 发送自定义事件
core.sendDataUpdateEvent();
```
