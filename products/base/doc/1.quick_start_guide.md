## 🎓 5 大组件速览

### 1️⃣ systems/base（核心基础）

**核心组件**：
- **Context** - 系统上下文（大脑）
- **Manager** - 应用管理器（管家）
- **App** - 应用基类（蓝图）
- **Display** - 显示管理（屏幕）
- **Event** - 事件系统（调度中心）

**核心接口**：
```cpp
// Context
Display& getDisplay();
Manager& getManager();
Event& getEvent();

// Manager
int installApp(App* app);
bool startApp(int id);
App* getActiveApp();

// App (虚函数接口）
virtual bool run() = 0;      // 创建 UI
virtual bool back() = 0;      // 返回键

// Display
lv_obj_t* getMainScreen();
lv_obj_t* getSystemScreen();

// Event
bool registerEvent(...);
bool sendEvent(...);
```

**学习优先级**：⭐⭐⭐⭐⭐（必须掌握）

---

### 2️⃣ systems/speaker（智能音箱）

**核心组件**：
- **Speaker** - 音箱系统主类
- **AI_Buddy** - AI 伴侣
- **AppLauncher** - 应用启动器
- **Keyboard** - 虚拟键盘
- **QuickSettings** - 快捷设置
- **Gesture** - 手势识别

**核心接口**：
```cpp
// AI_Buddy
bool isSpeaking();
bool isWiFiValid();
void sendAudioEvent(const AudioEvent& event);
ai_framework::Expression expression;

// AppLauncher
bool addIcon(uint8_t page_index, const AppLauncherIconInfo_t& info);
bool scrollToPage(uint8_t index);

// Keyboard
bool setVisible(bool visible);
bool setMode(lv_keyboard_mode_t mode);

// QuickSettings
bool setVolume(VolumeLevel level);
bool setBrightness(BrightnessLevel level);
bool setWifiIconState(WifiState state);
```

**学习优先级**：⭐⭐⭐⭐（音箱项目必学）

---

### 3️⃣ gui（图形界面）

**核心组件**：
- **Style System** - 样式定义系统
- **StylesheetManager** - 样式表管理
- **LVGL Wrapper** - LVGL 封装
- **AnimPlayer** - 动画播放器

**核心接口**：
```cpp
// Style System
StyleSize::RECT(100, 50);
StyleFont::SIZE(16);
StyleColor::COLOR(0xFFFFFF);
StyleImage::IMAGE(&my_img);
StyleAlign::CENTER();
StyleGap::AROUND(10, 10, 10, 10);

// LVGL Wrapper
LvHelper::createObj(parent);
LvHelper::createTimer(callback, 1000, nullptr);
LvHelper::createAnimation();

// AnimPlayer
bool begin(const AnimPlayerData& data);
bool sendEvent(const Event& event);
```

**学习优先级**：⭐⭐⭐⭐⭐（UI 开发必学）

---

### 4️⃣ ai_framework（AI 框架）

**核心组件**：
- **Agent** - AI 聊天代理
- **Expression** - 表情表达系统

**核心接口**：
```cpp
// Agent
bool configCozeAgentConfig(...);
bool sendChatEvent(const ChatEvent& event);
bool hasChatState(ChatState state);
static std::shared_ptr<Agent> requestInstance();

// Expression
bool setEmoji(const string& emoji);
bool setSystemIcon(const string& icon);
bool insertEmojiTemporary(const string& emoji, uint32_t duration_ms);
```

**学习优先级**：⭐⭐⭐（AI 功能必学）

---

### 5️⃣ services（服务）

**核心组件**：
- **StorageNVS** - NVS 存储服务

**核心接口**：

```cpp
// StorageNVS
bool setLocalParam(const Key& key, const Value& value);
bool getLocalParam(const Key& key, Value& value);

```

**学习优先级**：⭐⭐⭐（数据持久化必学）

## 🔍 接口查找技巧

### 场景 1：我想创建一个按钮

**步骤**：
1. 打开 `interface_cheatsheet.md`
2. 找到 `gui` → `StyleSize`
3. 查看如何创建尺寸：`StyleSize::RECT(100, 50)`

**代码**：
```cpp
StyleSize btn_size = StyleSize::RECT(100, 50);
lv_obj_t *btn = lv_button_create(parent);
lv_obj_set_size(btn, btn_size.width, btn_size.height);
```

### 场景 2：我想创建一个定时器

**步骤**：
1. 打开 `interface_cheatsheet.md`
2. 找到 `gui` → `LvTimer`
3. 查看构造函数：`LvTimer(TimerCallback callback, uint32_t period, void* user_data)`

**代码**：
```cpp
auto timer = LvHelper::createTimer([](void *data) {
    printf("Timer tick\n");
}, 1000, nullptr);
timer->begin();
```

### 场景 3：我想保存一个参数

**步骤**：
1. 打开 `interface_cheatsheet.md`
2. 找到 `services` → `StorageNVS`
3. 查看方法：`setLocalParam(const Key& key, const Value& value)`

**代码**：
```cpp
StorageNVS &storage = StorageNVS::requestInstance();
storage.setLocalParam("volume", 50);
```

## 📞 需要帮助？

### 常见问题

**Q: 我应该从哪个组件开始学？**
A: 推荐从 `systems/base` 开始，理解 Context、Manager、App 这三个核心组件。

**Q: 我需要记住所有接口吗？**
A: 不需要！速查表就是为了随时查阅而设计的。关键是理解"有什么"和"怎么用"。

**Q: 接口太多记不住怎么办？**
A: 多查阅，多用。用的多了自然就记住了。开始阶段以"能查到"为目标。

**Q: 如何快速找到我需要的接口？**
A:
1. 先确定属于哪个组件
2. 在速查表中找到该组件
3. 在该组件下搜索相关方法名
